# UI audit — 15 November 2026

Audit of Cinder Teacher, Cinder Student and Cinder Host before the UI rework on
branch `claude/ui-rework-5f8e74`. Every item has an ID so later commits can say
what they resolved. Status is updated as the work lands.

## How this was checked

- Test data: a fresh Host data folder (`C:\Users\Neel\Downloads\Cinder-Test-Data`)
  filled by `scripts/seed-test-data.mjs` (Cinder Test School: 2 teachers,
  10 students, 4 classrooms with one left empty, materials, assignments,
  submissions, grades, comments, attendance, a quiz with attempts, a live
  session).
- Teacher and Student were clicked through in the in-app browser against the
  seeded Host on `127.0.0.1:7373` (Host answers plain HTTP to this computer
  only), at 1280×800 and 960×640, in Light and Dark.
- Desktop control of the Tauri windows was declined, so the native-only parts
  were **not** exercised: secure session storage, the Host security-code
  prompt (deferred to the security review anyway), file dialogs, the updater,
  and the PDF viewer inside WebView2/WebKitGTK. Cinder Host's UI only works
  through Tauri commands, so it was audited from its source
  (`apps/host/src/App.tsx`) rather than clicked.

Severity: **P0** broken or loses data, **P1** clearly wrong or confusing,
**P2** polish.

## Top findings

1. **P0 — Students could not answer any quiz.** Saving an answer bound eight
   values to seven SQL placeholders, so every answer returned a server error.
   Present since 0.10.0. *Fixed in `c3f39f0` with a test.*
2. **P0 — The Gradebook spreadsheet does not draw.** Univer mounts but never
   creates its canvas; the sheet area stays blank. Console shows React's
   "Attempted to synchronously unmount a root while React was already
   rendering". The default classroom is also the alphabetically first one,
   which may be empty.
3. **P1 — Cancelling a quiz short-answer grade records 0 points.** Grading
   uses `window.prompt`; `Number(null)` is `0`, which passes the finite check
   and is saved.
4. **P1 — Three different visual languages.** Teacher is a dark-green
   dashboard with eyebrow labels and stat cards; Student uses huge Georgia
   headings, monospace eyebrows and widget cards; Host is a third style. Three
   themes use three accents (`#17463e`, `#df6c3e`, `#ec6338`), none of them
   brand Ember `#B24E17`.
5. **P1 — The wordmark is re-typeset.** Teacher's top bar sets "CINDER" in
   the UI font next to the page title, which `BRAND.md` forbids.
6. **P1 — Filler copy everywhere.** Marketing hero on both sign-in screens and
   an explanatory sentence under nearly every heading (full list in T-02, S-02).
7. **P1 — Student submission is a two-step detour.** To hand in work a
   student must first write a note elsewhere, then pick it from a drop-down on
   the assignment. The submitted text is never shown back to them.
8. **P1 — Fake or dead UI.** Student's notification bell always says "Nothing
   new."; the marks list says "Marked" without the mark; Host shows the
   teacher setup PIN in the error slot.
