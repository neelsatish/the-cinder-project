# Future features — for review

Larger pieces of work that came up during the November 2026 UI rework and were
left out because each needs more time or a decision first. Nothing here is
promised or built. Size is rough: **S** a day or two, **M** about a week,
**L** several weeks or a design decision first.

## Classwork

| Feature | Why it is worth it | Size |
| --- | --- | --- |
| Students reply to teacher comments | Feedback becomes a conversation instead of a one-way note; needs a route, notifications in Teacher and a rule on who can delete what. | M |
| Hand in photos or PDFs | Much school work is on paper; letting a student attach a photo of a page would cover it. Upload checks already exist for PDF and images. | M |
| Marking rubrics | Criteria with levels make marking faster and fairer, and give students clearer feedback than one number. | M |
| Publish assignments at a set time | Teachers can prepare work the evening before without it appearing early. | S |
| More quiz question types | Multiple answers, numbers within a tolerance, and matching cover most of what teachers set. | M |
| A quiz question bank | Reuse questions across quizzes and classrooms instead of copying quizzes. | M |
| Weighted gradebook categories and term grades | Teachers need homework, tests and projects to count differently, and a term summary. | M |

## Students' own work

| Feature | Why it is worth it | Size |
| --- | --- | --- |
| Copy notes to Cinder Host | Notes live only on the device today; a wiped or shared computer loses them. A private, per-student copy on Host would protect them. | L |
| Folders or tags for notes, and search inside Library PDFs | Notes are one flat list; a term's worth gets hard to find. | M |

## Running the school

| Feature | Why it is worth it | Size |
| --- | --- | --- |
| Register reports and export | A term summary per student and a CSV for the school office, from data Cinder already keeps. | S |
| Printable report for each student | Marks, attendance and feedback on one A4 page for parents' evenings. | M |
| Live classes without polling | The live view asks Host every few seconds; a push connection would feel instant and use less network. | M |
| Backups while Cinder Host is closed | Daily backups only run while Host is open; an operating-system task would keep them going. | M |

## Open decisions (from the backlog)

| Feature | Why it is worth it | Size |

| Android or tablet access | Schools have asked; needs a decision on Student only or Teacher too, and on a native app or browser. | L |
| Homework away from the school network | Needs a decision on what syncs later and how conflicts are handled. | L |
